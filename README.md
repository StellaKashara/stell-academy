# stell-academy
    Site officiel de Stell’A-cademy.

## Modifier le site
Les pages se modifient dans `_source/` (gabarit commun + une page par fichier dans `_source/pages/`), puis :

    python3 _source/construire.py

## Voir le site en local

    python3 -m http.server 8000
    # puis ouvrir http://localhost:8000

Contenus, photos et configuration du formulaire à compléter : voir `A-COMPLETER.md`.
