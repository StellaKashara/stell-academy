# Site Stell’A-cademy — consignes de travail

- Site statique publié par GitHub Pages depuis la branche `main` (dossier racine).
- Les pages se modifient dans `_source/` (gabarit commun + une page par fichier dans `_source/pages/`),
  puis on reconstruit le site : `python3 _source/construire.py`. Ne pas modifier les `index.html` générés à la main.
- `[[texte]]` dans une page source affiche un emplacement « À COMPLÉTER » : ne jamais inventer
  coordonnées, numéros légaux, logo, témoignages ou références clients.
- Le logo officiel n’est pas encore fourni : le nom reste en texte, ne pas recréer de logo.
- Git : Claude gère les branches, commits, fusions et envois. Travail sur `version-test`,
  aperçu privé (Artifact « Aperçu Stell’A-cademy ») envoyé à la fondatrice, puis fusion dans `main`.
- Préprod : le site GitHub Pages (branche `main`) sert de préproduction depuis le 11/11/2026 :
  https://stellakashara.github.io/stell-academy/ — chaque fusion dans `main` le met à jour.
  La mise en production (vrai nom de domaine / hébergement final) reste à décider avec la fondatrice.
- Ne jamais ajouter au dépôt (public) le cahier des charges ou toute information interne.
- Explications à la fondatrice : en français, simples, groupées, sans jargon (elle travaille sur iPad).
